Every use is written to a hash-chained audit trail, with the program that asked.

1. Intercepting keys written to ~/.aws

The key is sealed and read back before the file is touched.

1
You→~/.aws/credentials
aws configure, or paste a key
2
~/.aws/credentials→launchd
The file changed (WatchPaths), or the 5-minute sweep runs
3
launchd→aws-cli-zsp import --auto
Finds every profile with an aws_secret_access_key
4
aws-cli-zsp→Secure Enclave
Public half of the guarded enclave key (no prompt to seal, only to open)
5
aws-cli-zsp→vault/
Seal: ECDH + HKDF + AES-GCM, profile name bound in. Then read back and verify
6
aws-cli-zsp→~/.aws/credentials
Remove the key lines (atomic rewrite, mode 0600)
7
aws-cli-zsp→~/.aws/config
credential_process = aws-cli-zsp credential-process --profile NAME
8
aws-cli-zsp
Audit: key.imported, hash-chained

3. How the AWS CLI gets credentials

The CLI and every SDK run credential_process and read JSON from it.

1
aws s3 ls --profile bedrock→aws-cli-zsp
Runs credential_process from ~/.aws/config
2
aws-cli-zsp→vault/
Is there a session for bedrock with more than 5 minutes left?

Yes: most commands

3
Unseal it with the quiet key. No prompt.
4
Audit: session.served, with who asked
OR

No: the first command each hour

3
Secure Enclave→You
Touch ID: “AWS CLI: ZSP is trying to unlock your bedrock AWS key…”
4
The long-lived key is opened, in memory only
5
aws-cli-zsp→AWS STS
GetSessionToken: a temporary key, 1 hour by default
6
Seal the session (quiet key), drop the long-lived key, audit session.issued
7
aws-cli-zsp→aws
The session as JSON. The CLI signs the request with it.

Approving from your phone

Claude Code over Remote Control, nobody at the Mac.

1
Claude Code (on the Mac)→aws-cli-zsp
aws s3 ls --profile bedrock
2
aws-cli-zsp→Claude Code
No session and nobody at the Mac: fails at once instead of a Touch ID prompt nobody sees, and says to ask for a code
3
Claude Code→You (phone)
“I need the 6-digit code for bedrock”
4
You (phone)→Claude Code
123456, from your authenticator app
5
Claude Code→aws-cli-zsp
aws-cli-zsp approve --profile bedrock 123456
6
aws-cli-zsp→AWS STS
GetSessionToken with your phone's MFA serial and the code. AWS checks it
7
aws-cli-zsp
Seal the session, audit session.issued approved=mfa-code
8
Claude Code→aws-cli-zsp
Runs the command again: the cached session, no prompt for the rest of the hour
